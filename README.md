## 📖 项目简介

**诗云（ShiYun）** 是一款专注于中华古典诗词阅读的 Android 原生开源应用。项目以“**重温古典诗意、探寻中文版式美学**”为初心，提供随心浏览、意境检索、体裁分类、双击收藏、深度排版调节与多套国风古典主题等核心体验。

本项目为**纯粹的个人开源公益作品**，代码完全开源，**100% 纯本地离线运行**，不含任何商业广告、无任何隐私索取、无账号绑定限制。支持用户自愿赞助或赞赏，不以收费为主要目的。

## 🌟 项目主要特点

- **端庄雅致的古典排版**：深入结合中国古典诗词文体特性，依绝句、律诗自然分联留白，词阕自然分隔，小序题记独立排布，呼吸舒朗。
- **十套国风主题与水墨意象**：涵盖经典宣纸古籍到四时流转共 10 套深浅配色方案，每套主题深度覆盖全应用各级界面，辅以专属色调的水墨山水留白背景。
- **单手灵动微交互**：首页卡片支持上下左右四向灵敏滑动切换；详情页支持**正文全区域双击手势快速收藏**，辅以温润宣纸微动弹窗反馈。
- **本地字体自由导入**：在内置系统默认、系统衬线与系统等宽字体的基础上，开放支持用户自选导入本地任意 `.ttf` / `.otf` 中文字体。
- **零网络纯净单机体验**：无需申请联网权限，全量数据本地内置，真正做到秒开即读、安静无扰、隐私坚如磐石。

## 🛠️ 当前已实现的功能

当前公开测试版（v0.1.0-beta.1）已完成并经实机验证的核心功能如下：

1. **首页诗词推荐与滑动手势**：
   - 卡片居中展示精选诗句名作，首次启动带有轻量手势指引；
   - 支持**上下左右四向滑动手势**（左滑/上滑下一首，右滑/下滑上一首），采用主轴加速度与位移综合判定算法；
   - 推荐序列采用本地防重抽样，保证相邻两首作品绝不重复。
2. **诗词详情阅读与排版**：
   - 诗词正文采用纵向平滑滚动排布，支持长诗、题记与小序；
   - 选本模式下底部专属提供「上一首 / 下一首」连续切篇浏览栏。
3. **阅读排版与个性化设置**：
   - **正文字号**：支持在 **14 ~ 34 sp** 范围内按 1sp 步长自由微调（默认 22 sp）；
   - **正文字重**：支持常规（Normal）、适中（Medium）、加粗（Bold）三阶调节；
   - **行高倍率**：支持在 **1.30x ~ 2.40x** 范围按 0.05x 连续缩放（默认 1.70x）；
   - **字间距与结构间距**：支持字间距（0.0 ~ 3.0 sp）、左右阅读边距（12 ~ 40 dp）、诗句行间距（4 ~ 18 dp）、分联留白（8 ~ 32 dp）、分阕留白（10 ~ 36 dp）；
   - **首行缩进**：古文/长篇段落支持 0 或 2 全角空格缩进切换。
4. **字体引擎与本地字体导入**：
   - 内置支持系统默认、系统衬线（Serif）、系统等宽（Monospace）字体；
   - 开放支持用户调用系统选择器导入个人设备本地的 `.ttf` 或 `.otf` 格式字体文件，自动解析并在阅读页生效。
5. **双击收藏与藏卷每日名句**：
   - 阅读页支持正文全区域**双击手势快速收藏/取消收藏**，右上角红心图标同步响应；
   - 藏卷（收藏页）为空时，自动轮播四句温润名言（同日多次进出保持稳定，跨日按序顺延，再次变空稳定维持当天句，不随机重置）；
   - 收藏作品集中管理，支持一键移除。
6. **检索、分类与选本体系**：
   - 搜索页无边框沉浸设计，居中意境提示「众里寻他千百度」，输入后实时按作品标题、作者姓名或正文模糊检索并高亮；
   - 分类页支持按体裁（五绝、七绝、五律、七律、古风、词等）与朝代快速筛选；
   - 内置选本目录体系，方便专题品读。
7. **流畅的容器展开转场动效**：
   - 首页卡片及分类列表进入详情页时，采用基于 Jetpack Compose 的流体容器展开（Container Transform）无缝几何形变与收拢动效。
8. **本地分卷运行日志系统**：
   - 本地循环日志记录，藏卷页提供「运行日志」弹窗，支持查看日志统计、一键导出至 Downloads 目录或清空日志。

## 📚 内置诗词数据说明

诗云 v0.1.0-beta.1 随安装包内置收录了 **600 首唐宋经典名篇**：

- **唐代诗歌（320 首）**：完整覆盖《唐诗三百首》选本体系，涵盖五言古诗、七言古诗、五七言绝句、五七言律诗、乐府等各时期代表作（李白、杜甫、王维、白居易、李商隐、孟浩然等）；
- **宋代词作（280 首）**：完整覆盖《宋词三百首》选本体系，涵盖苏轼、辛弃疾、李清照、晏殊、欧阳修、柳永、周邦彦等历代词家传世名篇；
- **纯本地打包**：所有作品、小序及选本元数据存放在应用资产目录（`assets/data/`）中，离线可用，启动零网络延迟。

## 🧰 技术栈与工程规范

- **核心语言**：Kotlin 2.2.10
- **构建工具**：Android Gradle Plugin 9.5.1 / Gradle 9.6.0
- **UI 框架**：Jetpack Compose（基于 Compose BOM 2026.02.01）
- **设计规范**：Material Design 3 (M3)
- **运行环境**：Android 10.0 (API 29) ~ Android 17 (API 37)
- **JSON 解析**：Android 原生 `org.json`（零第三方依赖引入）
- **架构设计**：Kotlin 响应式状态流（`StateFlow`）+ 模块化单向数据流

## 🔒 隐私与离线纯净承诺

- **无网络权限**：诗云在 `AndroidManifest.xml` 中**完全未声明网络访问权限（`INTERNET`）**，系统底层阻断任何网络访问；
- **零隐私索取**：不获取通讯录、相机、位置、短信、设备唯一识别码等任何敏感个人信息；
- **数据本地存储**：用户的收藏记录、排版偏好及导入字体全部保存在手机本地的应用私有沙盒中；
- **运行日志可控**：项目内置日志仅记录界面事件与本地错误，默认存放于内部私有目录，用户可在“藏卷 - 运行日志”中随时查看、导出或清空。

## ⚠️ 当前版本暂不支持的功能说明

为避免虚假宣传与功能误解，请知悉以下功能在 **v0.1.0-beta.1** 中**尚未开发或暂不支持**：

1. ❌ **单篇诗词仿真纸质翻页**：当前阅读页为舒朗平滑的垂直连续滚动阅读（选本场景下仅支持底部“上一首/下一首”切篇）；
2. ❌ **云端账号同步与 WebDAV 备份**：当前为纯单机设计，无跨设备云端同步；
3. ❌ **诗词名句图片分享海报**：目前暂不支持生成排版分享长图或卡片；
4. ❌ **阅读历史与时长统计**：目前仅有“收藏”功能，无阅读足迹、进度记忆或时长数据统计；
5. ❌ **基于算法的智能推荐**：首页为相邻防重的本地随机抽样，非基于个人偏好的 AI 算法；
6. ❌ **标点悬挂压缩**：当前仅保留权威古籍原文原有标点，尚未内置标点悬挂与压缩排版引擎。
